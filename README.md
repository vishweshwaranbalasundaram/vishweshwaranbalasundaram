## Featured Projects

### 1. [Attend-IQ — Smart Attendance Management](https://github.com/vishweshwaranbalasundaram/Attend-IQ)

**Status:** Academic project · Java console application

A database-backed attendance management system built with **Java, JDBC, MySQL, and Maven**. Its source includes service and repository layers, a console UI, database schema and migrations, and unit/integration test classes.

**Implemented areas documented in the repository:**
- Student, faculty, subject, and enrollment management
- Class-session and attendance-record workflows
- Attendance calculations, shortage reporting, and CSV export
- Faculty authentication-related services and attendance audit records

[Source code and setup](https://github.com/vishweshwaranbalasundaram/Attend-IQ) · [Build workflow](https://github.com/vishweshwaranbalasundaram/Attend-IQ/actions/workflows/verify.yml)

### 2. [HackTrail — Hackathon & Tech Event Finder](https://github.com/vishweshwaranbalasundaram/hacktrail)

**Status:** Personal project · static web application

A single-page finder for hackathons and technology events across India, implemented in **HTML, CSS, and JavaScript**.

**Features documented in the repository:**
- Filter events by state, date range, level, and category
- Optional proximity-based sorting using browser location
- Shareable filter links and direct search links for event platforms
- A built-in fallback dataset, with an optional external sheet-based feed

[Inspect the implementation](https://github.com/vishweshwaranbalasundaram/hacktrail)

### 3. [E-Commerce Customer Churn Prediction](https://github.com/vishweshwaranbalasundaram/ecommerce-churn-prediction)

**Status:** Machine-learning project

A Python workflow using the **UCI Online Retail dataset** to study whether customers make a completed purchase during a future 90-day window. The repository contains an analysis pipeline, reusable data/model modules, report-generation code, a Streamlit dashboard, and a test for transaction cleaning.

**Methodology documented in the repository:**
- Transaction cleaning and customer-level feature engineering
- Baseline/model comparison and cross-validation
- Train/validation/test separation and validation-based threshold selection
- Evaluation reports, plots, and feature-importance output

[Source code and run instructions](https://github.com/vishweshwaranbalasundaram/ecommerce-churn-prediction)

### 4. [SafePay Guard OS](https://github.com/vishweshwaranbalasundaram/safepay-guard-os)

**Status:** Front-end prototype / designathon project

A browser-based scam-awareness and financial-safety experience built with **HTML, CSS, and JavaScript**, including scam-message analysis, simulated scam education flows, visual dashboards, and a rule-based assistant.

**Scope note:** The repository README explicitly describes authentication as a front-end demonstration and the assistant as rule-based rather than a cloud LLM. This is presented as a prototype—not as a production payment system or a deployed autonomous-agent platform.

[Inspect the prototype and its limitations](https://github.com/vishweshwaranbalasundaram/safepay-guard-os)
