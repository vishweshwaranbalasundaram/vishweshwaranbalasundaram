## Important project-name mismatch

The profile calls `safepay-guard-os` “Paytrix / Safe Pay Guard” and describes a safety kernel for AI-agent purchases, fraud/price scoring, spend-velocity limits, hash-chained ledger, and Razorpay. The inspected SafePay Guard README instead documents a scam-awareness/financial-safety front-end prototype, a rule-based assistant, and front-end-only authentication. Those descriptions are not interchangeable. The revised README uses the actual repository name and only claims what its repository README supports. If Paytrix is a separate codebase, add its correct repository URL and audit it separately before featuring it.
